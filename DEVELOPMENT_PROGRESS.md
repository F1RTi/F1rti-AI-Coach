# Журнал разработки F1rti AI Coach

Проверка от 18 ноября 2026 года. Проект создан в пустой рабочей папке. За основу взяты Python 3.12 x64, FastAPI, SQLite и React/TypeScript. Окно приложения использует установленный браузер, трей и Windows DPAPI. Версии зависимостей закреплены в requirements.lock и frontend/pnpm-lock.yaml.

## Результаты проверок

- Pytest завершил 23 теста, все прошли. Starlette выдал одно предупреждение о будущем переходе тестового клиента с HTTPX на HTTPX2.
- TypeScript прошёл строгую проверку типов. Vite собрал статический интерфейс. Ruff прошёл проверки синтаксиса, импортов и неиспользуемого кода (E9, F, I).
- End-to-end в Microsoft Edge использовал отдельную SQLite и тестовый транспорт FACEIT. Проверены первый экран, ввод ключа через форму, синхронизация, открытие матча, ручной план, отметка выполнения, импорт публичной демо, выбор раунда и типа события, просмотр HTML и скачивание PDF. Исключений React в браузере не было.
- Первоначальный экспорт PDF через печать браузера зависал. Он заменён на ReportLab с встраиванием кириллического шрифта. Проверены сигнатура PDF, экспорт из встроенного Python и отрисованная страница с кириллицей и таблицей.
- Проверены запросы без токена и с посторонними Host/Origin, хранение ключа в DPAPI, отсутствие ключа в ответе состояния, подтверждение сброса и сохранение исходных файлов. Тестовые данные не входят в дистрибутив.
- Публичный файл объёмом 60 601 900 байт разбирался примерно за 1,6–2 секунды при локальном замере с прогретым файловым кэшем. Расчёт окна из 100 матчей и группировка 1 000 синтетических матчей в памяти заняли около 0,02 секунды. Эти измерения относятся к данной машине и выборке.
- Проверка установки выполнена на Windows x64, сборка 26200, версия 25H2. Временные копии приложения, тестовые снимки интерфейса и отчёты находятся в .work. Установщик проверялся с перенаправлением ярлыков в изолированную папку.

## Открытые пункты приёмки

1. Для проверки фактического player_id, текущего ELO, истории и доступности дополнительных полей F1rti нужен пользовательский FACEIT Data API key. Его вводят в приложении. Ни одна цифра из тестов не является статистикой F1rti.
2. Живой вызов внешнего AI-провайдера ожидает выбранного пользователем адреса, модели и ключа. Для локальных правил и планов это подключение необязательно.
3. Доступ к FACEIT Downloads API не предоставлялся. Автоматизация начинается с файлов в папке наблюдения или ручного импорта.
4. Валидирован один публичный Source 2 replay и нормализованная фикстура. Покрытие иных версий игры и карт ограничено доступными записями. Тактические флаги по геометрии служат поводами для просмотра раунда. Скорость реакции, движение мыши и точность наведения приложение не оценивает.
5. SQLite используется напрямую. Для будущего перехода на PostgreSQL потребуется адаптация SQL и миграций. История ELO накапливается с момента подключения, прогноз даты достижения цели отключён.
