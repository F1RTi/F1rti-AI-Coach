# F1rti AI Coach

Локальное приложение для анализа матчей CS2 игрока F1rti и движения к 3000 FACEIT ELO. Интерфейс на русском языке. В комплекте есть Python, интерфейс, аналитика и парсер. Для использования собранного приложения достаточно Windows 11 x64 и Edge или Chrome.

## Первый запуск

1. Откройте `release/F1rti-AI-Coach-Setup.exe` и подтвердите установку. Установщик создаёт ярлыки в меню «Пуск» и на рабочем столе. Код приложения устанавливается в отдельную папку текущего пользователя.
2. Нажмите «Подключить». Создайте серверный ключ Data API в своём приложении в кабинете разработчика FACEIT. Введите ключ в настройках и сохраните. Начнётся импорт истории F1rti. Первая загрузка большого профиля может занять значительное время. [Кабинет FACEIT](https://developers.faceit.com/).
3. В «Демозаписи» выберите файлы или перетащите их в окно. Для автоматического импорта укажите папку наблюдения. После разбора можно выбрать свой SteamID из состава записи и привязать запись к матчу. Без FACEIT-ключа также доступны импорт, выбор игрока и ручное планирование.
4. В «AI-тренер» откройте доказательства наблюдения. В «Тренировки» выберите период, сформируйте план и подтвердите выполнение упражнения. Если наблюдений мало, можно самостоятельно выбрать один из 11 навыков. Сложность занятия оценивается от 1 до 5.
5. В «Отчёты» откройте сохранённый срез или выгрузите HTML/PDF. Для выбора другой игровой сессии и добровольного дневника откройте «Статистика».

Ключи FACEIT и AI шифруются Windows DPAPI для текущего пользователя. Ключ AI необязателен. Для его подключения укажите адрес API, модель и ключ. Кнопка «Обновить приоритеты» передаёт провайдеру компактные наблюдения. Данные демозаписей и дневник остаются на компьютере.

Значок в системном трее открывает окно повторно. Закрытие окна оставляет фоновые задачи запущенными. Команда «Выход» в меню значка завершает приложение. Автозапуск при входе включается в настройках. «Приостановить анализ» находится в разделе демозаписей. Пауза сохраняется после перезапуска.

## Как читать результаты

- Окна в 5, 10, 20, 50 и 100 матчей сравниваются с предшествующими непересекающимися окнами. У каждой метрики есть источник, выборка и формула. K/D и K/R вычисляются по суммам парных наблюдений. ADR взвешивается по раундам. Пропуски обозначаются прочерком.
- История ELO начинается с первого снимка API. Для недельного или месячного изменения нужен снимок до границы периода. Для Δ сессии нужны снимки по обе стороны и отсутствие других сохранённых матчей между ними. Исторический максимум относится к собранным снимкам.
- У сторон, гранат и дуэлей есть отдельный источник CS2 demo. Включены завершённые раунды. Состав и стоимость снаряжения фиксируются в конце закупки или в начале раунда, если событие конца закупки отсутствует. Применения оружия, попадания, урон и убийства относятся к выбранному SteamID. Оружие последнего контакта в карточке дуэли определяется по событию смерти. Попадания считаются по событиям урона между этой парой до смерти в раунде.
- Размен определяется по ответному убийству союзником в пределах 320 игровых тиков. Повторные смерти группируются по клеткам карты в 256 игровых единиц. Расстояние до живых союзников, повторный контакт и маршрут после установки бомбы дают гипотезы для просмотра. Стены, видимость, намерения игрока и голосовые договорённости требуют ручной оценки.
- В записи доступны фильтр событий и переход к раунду и тику. Привязка к матчу выполняется вручную. Набор событий зависит от версии демо. Данные об ослеплении и уроне показываются при наличии соответствующих полей. Функции записи в матч, чтения памяти CS2 и управления клиентом отсутствуют.
- Тренер проверяет несколько воспроизводимых правил, включая первые дуэли, смерти без размена, стабильность ADR и устойчивый урон. К каждому выводу приложены наблюдения. Совместимый AI выбирает порядок этих направлений через JSON с проверкой всех идентификаторов. После подтверждённого занятия сравниваются исходная и последующая выборки. Для оценки по демо привяжите будущие записи к матчам с известным временем.
- Форматы «Неделя» и «Месяц» охватывают 7 и 30 дней. Длительность задаётся в настройках. Для короткой разминки и восстановления применяются меньшие бюджеты. Основной дневной план обновляется по результатам синхронизации и обработки демо.

## Хранение и восстановление

Папка данных по умолчанию — `%LOCALAPPDATA%\F1rti AI Coach\data`. В ней находятся `coach.sqlite`, копии демо по SHA-256 и зашифрованные файлы ключей. Одна запись хранится один раз, в том числе при импорте одновременно из .dem и .dem.gz. SQLite использует транзакции, внешние ключи, WAL и версионирование схемы.

«Создать копию базы» делает согласованную копию SQLite и показывает её путь. Для полного архива завершите приложение через трей и скопируйте папку данных. Для восстановления безопаснее использовать отдельную папку и запуск `desktop.py --data ПУТЬ`. При восстановлении из одной копии базы поместите её под именем `coach.sqlite` в новую папку. Для повторного разбора перенесите также каталог `demos`. При переносе на другого пользователя введите ключи заново.

Сброс в настройках требует паузы и ввода слова подтверждения. Он удаляет рабочие данные, импортированные копии и ключи. Резервные копии и оригиналы в папке наблюдения остаются у пользователя. Для удаления установленного приложения отключите автозапуск, завершите работу из трея и удалите папку установленной версии и ярлыки.

## Разработка

Backend использует Python 3.12, FastAPI, HTTPX, Pydantic, SQLite и demoparser2. Интерфейс написан на React и TypeScript, собирается Vite. Окно Edge/Chrome работает в режиме приложения. Локальный сервер слушает случайный порт 127.0.0.1 и проверяет Host, Origin и токен процесса. Один последовательный фоновый исполнитель обслуживает очередь, а нативный парсер запускается дочерним процессом. Онлайн-ресурсы для отображения интерфейса не нужны.

Для запуска из исходников установите Python 3.12 x64, Node.js 22.12+ и pnpm 11. В PowerShell из корня проекта выполните

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend run build
.\Start.cmd
```

Для сборки установщика на Windows нужен системный компилятор C# .NET Framework x64. Скрипт загружает официальный CPython Embedded 3.12.10 x64, сверяет SHA-256, добавляет runtime-библиотеки и готовый frontend. Целевой компьютер использует вложенный интерпретатор. Результат появится в `release`.

```powershell
.\.venv\Scripts\python.exe scripts/package.py
```
